# 排障指南

排查顺序：**进程 → 端口 → QQ 登录状态 → OneBot 连接 → 接入规则 → 模型调用**。
先看状态，再改配置；不要用「改人设」「提高回复概率」去解决「没收到事件」。

## 部署阶段

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 下载卡住 / 部署失败 | 访问 GitHub、Node.js 官网或 npm 受阻 | 使用离线整合包；检查代理；确认安全软件未拦截 |
| 提示需要管理员确认 | 安装 C++ 运行库 | 允许安装；若要求重启，重启后再次运行部署入口 |
| 双击没反应 | 在压缩包预览窗口内运行，或只解压了部分文件 | 完整解压到本地固定目录后重试 |
| 校验失败 | 文件下载不完整或被替换 | 不要跳过校验，重新获取发行包 |

## 启动阶段

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 端口被占用 | 8080 / 3210 / 3000 / 3001 / 6099 已被其他程序使用 | 首次部署会自动选邻近空闲端口，以启动输出为准；也可在 `.env` 指定 |
| 后台打不开 | 服务未启动、端口不同、被防火墙拦截 | 看运行窗口日志；确认实际端口 |
| 重复启动 | 已有实例在运行 | 正常行为：会打开现有后台，不重复启动 QQ 服务 |
| 关窗口后服务停止 | 设计如此，非常驻服务 | 需要常驻请自行配置计划任务 |

## 运行阶段

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 后台能开，QQ 不能收发 | 未登录 / OneBot 未连接 | 查看真实登录状态与 OneBot 连接状态；服务运行 ≠ 账号在线 |
| 扫码后仍显示未登录 | 设备确认、验证码未完成，或风控拦截 | 由账号本人完成验证；不要尝试绕过 |
| QQ 在线但无回复 | 白名单、群聊总开关、响应模式、呼叫词、参与概率、模型设置 | 按顺序逐项核对；查看接收诊断与会话记录 |
| 后台完全没有消息记录 | 事件连接断开或协议端未上报 | 先查 OneBot WebSocket 与 NapCat 状态 |
| 模型报错 | 密钥、地址、模型名、额度、超时 | 查看后台 API 错误与用量；确认接口兼容 OpenAI 格式 |
| 表情概率 100% 却没有表情 | 无可用素材、标签不匹配、冷却中、好感度档位覆盖 | 检查素材与匹配规则；100% 不绕过素材缺失 |
| 发送显示「结果待确认」 | 发送超时，结果未知 | 不要立即重发，先观察对方是否已收到 |
| 接龙 `+1` 不生效 | NapCat 对消息结构或提交接口支持不足 | 属已知限制，不保证成功 |
| 桌面快捷方式失效 | 移动了部署目录 | 在原位置重新运行部署入口生成快捷方式 |

## 日志与诊断

| 位置 | 内容 |
| --- | --- |
| 运行窗口 | 启动与部署过程输出 |
| `data/` | 管理密码、部署记录、QQ 独立资料 |
| `qq-agent/data/` | 业务配置、数据库、消息、会话、素材 |
| NapCat 运行目录 | 协议端日志 |

分享诊断文件前务必检查隐私：日志、会话、聊天记录、截图、令牌都可能包含个人信息。

## 安全提醒

- 不要把 OneBot、业务后端或 NapCat WebUI 直接暴露到公网；远程访问需另行配置 HTTPS、防火墙与访问控制。
- 不要提交 `.env`、`data/`、`qq-agent/data/`、`.runtime/`、数据库与日志到公开仓库。
