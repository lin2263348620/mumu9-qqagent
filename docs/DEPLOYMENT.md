# 部署指南（Windows）

## 1. 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11，x64 |
| 磁盘 | 建议至少 1 GB，包含下载、解压与运行空间 |
| 网络 | 能访问已配置的模型服务；使用离线包时首次部署无需访问 GitHub / Node.js 官网 |
| QQ 账号 | 能自行完成扫码、设备确认及可能出现的验证 |
| 模型接口 | 自备 OpenAI 兼容接口、密钥与可用模型 |

> 未验证 ARM Windows。Linux 请使用对应发行包，不要运行本目录下的 `.cmd` 文件。

## 2. 解压

将 `BOT-Windows-一键部署离线整合包-v1.0.0.zip` 内的 `bot-windows` 文件夹完整解压到固定、可写的目录，例如 `D:\bot`。

- 不要在压缩包预览窗口里直接运行。
- 不要只提取启动脚本。
- 路径不宜过长，也不要在解压后移动目录（桌面快捷方式指向部署位置）。

## 3. 校验发行包（建议）

```powershell
Get-FileHash .\BOT-Windows-一键部署离线整合包-v1.0.0.zip -Algorithm SHA256
```

```bat
certutil -hashfile BOT-Windows-一键部署离线整合包-v1.0.0.zip SHA256
```

结果应与 Release 页面给出的 SHA256 一致。包内 `bot-windows/manifest-sha256.json` 提供解压后逐文件校验清单。

## 4. 首次部署

双击 `一键部署启动.cmd`。程序会依次：

1. 检查 Node.js，缺失或低于 22.13 时使用内置的 22.22.0 便携版。
2. 检查 Microsoft C++ 运行库，缺失时安装内置安装程序（需 Microsoft 签名校验，可能要求管理员确认或重启）。
3. 安装后台生产依赖。
4. 准备固定版本的官方 NapCat，并校验 SHA256。
5. 选择空闲本地端口，生成内部连接配置与随机令牌。
6. 启动管理后台与 QQ 服务，等待登录接口就绪。
7. 创建桌面 `bot管理后台` 快捷方式，打开浏览器与密码文件。

首次部署必须保持运行窗口打开。

## 5. 登录与配置

1. 管理密码首次随机生成：`data/admin-password.txt`。
2. 登录后台后进入 QQ 登录页面，用手机 QQ 扫码。
3. 配置模型 API、人设、主人 QQ、接入白名单、响应模式与表情素材。

**后台可打开、QQ 服务已启动、账号已登录、bot 能生成回复，是四个不同状态。** 未配置模型或未允许该会话时，不应期待普通 AI 回复。

## 6. 环境变量

复制 `.env.example` 为 `.env` 后按需修改，正常一键部署不要求手工设置。

| 变量 | 作用 |
| --- | --- |
| `ADMIN_PASSWORD` | 自定义管理密码，至少 12 字符；留空则随机生成 |
| `PORT` | 管理入口端口，默认 8080 |
| `QQ_AGENT_PORT` | 业务后端端口，默认 3210 |
| `NAPCAT_DIR` | NapCat 目录覆盖 |
| `NAPCAT_START_SCRIPT` | NapCat 启动脚本覆盖 |
| `BOT_OPEN_BROWSER=0` | 禁用自动打开浏览器与密码记事本 |
| `BOT_USE_LOCAL_NODE=1` | 强制使用项目内置便携 Node |
| `BOT_SKIP_PROTOCOL=1` | 排障时只启动后台，不提供 QQ 收发 |

## 7. 日常启动与停止

- 启动：双击桌面 `bot管理后台`，或运行 `启动管理后台.cmd`（已在运行则只打开后台）。
- 停止：关闭运行窗口。
- 本版不是 Windows 常驻服务，不随系统启动。

## 8. 升级与清理

- 升级：保留 `data/`、`qq-agent/data/` 与 `.env`，替换其余文件后重新运行部署入口。
- 彻底清理：删除整个部署目录（会连同本地聊天数据、SQLite 数据库与 QQ 独立资料一起删除，请先备份）。
